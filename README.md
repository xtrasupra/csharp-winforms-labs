# C# / ЯМП · Windows Forms, 2 курс

Семь моих лабораторных работ второго курса по разработке настольных приложений на C#.

## О коллекции

Работы посвящены визуальному программированию: построению форм, обработке событий, меню, диалогам, вводу данных и учебным вычислениям. Сохранены код форм, файлы Designer, ресурсы и проекты.

## Запуск

Требуются **Windows** и **.NET 10 SDK** с Windows Desktop. Откройте нужный `.csproj` в Visual Studio либо запустите `dotnet run --project <путь-к-проекту>`. Каждая работа запускается отдельно.

## Структура архива

Внешние папки унифицированы как `labs/Lab01`–`labs/Lab07`; внутренние имена проектов и пространств имён сохранены, чтобы не нарушать привязки Designer и `.resx`. Исключены сборочные файлы, локальные настройки IDE и повторное вложение папок.
